BURLEY'S WEBSITE - Acode setup
1. Extract burlyas-website.zip.
2. Open Acode and open the extracted folder.
3. Open index.html in browser / preview.
4. Keep the assets folder beside index.html, style.css and script.js.

Files:
- index.html: website structure
- style.css: design and responsive layout
- script.js: menu, category filters, cart and address interactions
- assets/: each logo/food image is a separate file

Note: This is a front-end demo. Real online payments, order submission, login,
live delivery tracking and database storage require a backend and payment provider.
Prices and menu items are sample/demo content and can be edited in script.js.
